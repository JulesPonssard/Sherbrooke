# Sherbrooke

Sommaire de mes travaux et projets à l'Université de Sherbrooke.

Chaque matière possède son propre dépôt : vous pouvez cloner uniquement le projet qui vous intéresse.

| Matière | Dépôt |
| --- | --- |
| Mathématiques | [Math](https://github.com/JulesPonssard/Math) |
| Imagerie médicale | [Imagerie-medicale](https://github.com/JulesPonssard/Imagerie-medicale) |
| Science des données | [Science-des-donnees](https://github.com/JulesPonssard/Science-des-donnees) |

## Récupérer une matière

Exécutez la commande correspondant à votre choix :

**Mathématiques**

```bash
git clone https://github.com/JulesPonssard/Math.git
```

**Imagerie médicale**

```bash
git clone https://github.com/JulesPonssard/Imagerie-medicale.git
```

**Science des données**

```bash
git clone https://github.com/JulesPonssard/Science-des-donnees.git
```

Les fichiers des matières sont désormais maintenus dans ces dépôts indépendants. Leur ancienne version reste accessible dans l'historique de ce sommaire.
